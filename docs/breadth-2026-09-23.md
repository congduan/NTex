# 广度测试发现清单（2026-09-23，HEAD 2f10eca）

用 10 份典型结构 LaTeX 样张（纯文字/目录/列表/数学/表格/浮体/双栏/中文/定理/hyperref）
与 pdfTeX GT 逐行对比（pymupdf 文本集合 diff + 行级几何 + 规则线）。样张与对比脚本、
双版 PDF 均为会话临时产物（/tmp/breadth-*），本文只留结论与最小复现。

**结果**：编译通过 7/10；文本级全对齐 b3（列表）、b6（浮体）两份；结构性失败 3 份
（双栏/ctex/hyperref）。此处只登记引擎侧发现，按修复优先级排序。

## P0 崩溃 / 内容丢失

| # | 缺陷 | 最小复现 | 现象 |
|---|---|---|---|
| 1 | ctexart 载入栈溢出 | `\documentclass{ctexart}\begin{document}x\end{document}` | rc=134，`has overflowed its stack` abort，无诊断输出 |
| 2 | 脚注不渲染 ✅已修 | `text\footnote{the note.}` | 正文上标 `1` 在，页底脚注文本整段消失（insert→页底投递断链）。**根因**：`\insert` 体只存 token 串从未排版（tex.web `begin_insert_or_adjust` 是 push_nest+内部垂直模式由主循环排版），ins 节点也被折进行盒没到断页器。修：体真排版成 vlist（`GroupKind::Insert`）+ 折行时按 adjust_tail 语义摘出 ins 节点 + fire_up 拼装 `box(class)`。GT 对照：页底横线 + `1 The note text.` 逐点一致（cmr8/cmss/cmex 字号、横线 x133.77 宽 137.5 全同）；残差：脚注首行整体右移 ~17.3pt（NTex 多一个 \parindent 空盒与一个空格字符节点，定性为排版残差另列） |
| 3 | 中文默认路径全丢 ✅已修 | article + UTF-8 中文源 | 多字节逐字节进字体（`Missing character: There is no ^^e5 …`）；`--cjk-fallback` 只接管码位 >0xFF 的字符，字节恒 <0x100 故永不触发；CLI 无 `--utf8` 开关（wasm 有 `set_utf8_input`，源内 `\utfinputmode=1` 可 opt-in）。**修**：`ntex-dvi` 加 `--utf8` 开关，且 `--cjk-fallback` 隐含开启 UTF-8 解码（xelatex 口径，`Typesetter::set_utf8_input`→`set_misc_int`，源内 `\utfinputmode=0` 仍可关）。验收：article+中文源 `--cjk-fallback FandolSong-Regular` Missing character 42→0，PDF 提取 `中文测试：这是一个汉字段落。` |
| 4 | 含全角标点的中文段落不断行 | `\utfinputmode=1` 后含 `，。、` 的段落 | 整段单行溢出页面（x 到 616pt > 612pt 页宽）；无标点段落断行正常 |

## 表示层差异（不算 bug，供裁决）

- 纸张：NTex letter(612×792) vs GT A4(595×842)——既有驱动分径裁决，版心一致。
- 嵌入字体无 ToUnicode：fi/ff 提取为 U+FB01、∇/∂/ρ 提取为字面位；影响复制/搜索/无障碍
  （视觉待 glyphpos 渲染对照定谳），建议列入字体嵌入 backlog。
- 断字质量：`sh-ould`/`disintegr-ates` 级劣质断点（preload_hyphen 补种后的残差）。
- CJK fallback 字体整包嵌入未子集化（4.9MB vs GT 34KB）。

## 验收面结论

已过硬：纯文字流式、列表三件套、浮动体（位置/尺寸/caption/\ref 两趟闭合）、
tabular+booktabs 规则装配、目录条目与页码、amsmath align/gather 主体、aux 两趟机制。
断在前：脚注、双栏、中文默认路径、hyperref/ctex 载入——均为典型文档常用件。
